Understand common phishing techniques and create awareness materials to educate users about identifying and preventing phishing attacks.

1. Email Phishing

* Verify sender identity.
* Avoid suspicious links.
* Enable Multi-Factor Authentication.
* Use strong passwords.
* Keep software updated.
